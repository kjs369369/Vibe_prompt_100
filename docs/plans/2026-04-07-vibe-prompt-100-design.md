# 바이브 코딩 시작 프롬프트 100선 — 웹페이지 디자인

## 개요
- **목적**: 강의 현장 시연 + 수강생 자료 배포용 단일 HTML 웹페이지
- **콘텐츠**: 14개 분야 100개 바이브 코딩 프롬프트
- **테마**: 키네틱 타이포그래피 (블랙/화이트/레드/로열블루)
- **브랜딩**: AICLab (김진수)

## 디자인 테마
- 주요 색상: 블랙(#000000), 화이트(#FFFFFF), 레드(#FF0000), 로열블루(#0048BA)
- 폰트: Black Han Sans (타이틀), Noto Sans KR (본문), Bebas Neue (영문 강조)
- 특징: 동적 텍스트, 인터랙티브 애니메이션, 대담한 서체 변형

## 헤더 & 히어로
- 후킹 타이틀: "코딩 몰라도 된다. 붙여넣기만 하면 웹앱이 나온다."
- 서브타이틀: "바이브 코딩 시작 프롬프트 100선 — AI 시대, 누구나 개발자"
- 상단 바: AICLab 브랜드 + 사용법 안내 버튼
- 키네틱 애니메이션: 글자 stagger 등장, 레드 강조 바운스, 서브타이틀 페이드인
- 스크롤 유도 버튼: "프롬프트 둘러보기"
- 사용법 모달: 3단계 안내 (클릭 → 복사 → 붙여넣기)

## 고정 헤더 (스크롤 시)
- AICLab 브랜드 + "바이브 코딩 100선" + 전체 펼치기/접기 버튼
- 블랙 배경 + 레드 1px 하단 라인

## 분야 토글 (아코디언)
- 14개 분야, 초기 상태: 전체 닫힘
- 분야 제목: ■ 블록 + 분야명 + 프롬프트 개수 + 화살표
- 열기 애니메이션: 화살표 회전 + 카드 순차 슬라이드다운
- 호버: 좌측 블록 레드 확장

## 프롬프트 카드
- 난이도 태그: [쉬움] 로열블루 배지, [보통] 레드 배지
- 번호 + 제목 (볼드 화이트 20px), 설명 한 줄 (회색 16px)
- 카드 배경 #111111, 호버 시 좌측 컬러 보더
- 복사 버튼: 제목 + 프롬프트 본문 복사, "복사 완료!" 애니메이션

## 푸터
- AI콘텐츠융합연구소 (AICLab) + 이메일 + 홈페이지
- 간결한 1~2줄 구성

## 반응형
- 데스크톱 (1024px+): 카드 2열, 타이틀 72px
- 태블릿 (768px~): 카드 1열, 타이틀 48px
- 모바일 (480px~): 카드 1열, 타이틀 32px

## 성능
- CSS @keyframes + transform 기반 애니메이션
- prefers-reduced-motion 대응
- 단일 HTML 파일, 외부 라이브러리 없음 (Google Fonts CDN만 사용)
